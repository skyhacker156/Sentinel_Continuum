Every inbound foreign artifact passes through the original 19-step Input Pipe,
then branches into this new workflow:

Step A — Identify Foreign Cluster

Classification based on:

Return address country

Postmark origin

Envelope design fingerprints (canonical list from Grok v1.0)

Subject line / offer type

Result becomes field #20 in the forensic record:

20. International_Cluster (I-0 … I-6)

Step B — Route to Proper Tray

If I-0 → Canada tray (process immediately)

If I-1 → UK/Ireland

If I-2 → India

If I-3 → Singapore

If I-4 → DE/NL
