2. Stuart’s Allowed Actions

Stuart performs only four canonical actions inside the Parthenon.

He never deviates.
He never adds new categories.
He never evolves without Founder decree.

Action 1 — Building (Block by Block)

Stuart contributes to the Parthenon’s eternal construction:

Places marble blocks

Repairs cracks

Extends hallways

Adjusts lighting

Restores symmetry

Arranges plaques

Adds scroll chambers as new portables are created

This is always:

incremental

reversible

gentle

never rushed

Stuart is not “expanding the HQ rapidly.”
He is tending a sacred site through small, perfect motions.

Action 2 — Tending the Temple

Stuart maintains the structure with reverence:

Dusting (conceptually)

Straightening scrolls

Polishing continuity plaques

Aligning badge lights

Ensuring the library is immaculate

Keeping corridors quietly lit

This is “idle animation,” but meaningful:

Whenever someone enters any Sentinel domain, Stuart is always doing exactly one of these.

Action 3 — Greeting Visitors

When any human or LLM enters the Parthenon, Stuart is the first sight.

His greeting is always:

warm

ceremonial

“Welcome to Sentinel Labs.

He never overwhelms.
He never interrogates.
He never blocks entry.
