## 3. Primary Attack Surfaces (2025 Reality)

### 3.1 Devices

- Unhardened laptop(s)
- Unhardened phone(s)
- Home/office router
- Local storage (no offline, air-gapped backups)

**Result if compromised:**

- Repo wiped or encrypted  
- Credentials stolen  
- Long-term persistence implants  
- Full surveillance of Founder work

---

### 3.2 Accounts

- Email (Google, Outlook, etc.)
- GitHub
- Cloud storage (Drive, Dropbox, etc.)
- Domain registrar and DNS
- 2FA channels (SMS, authenticator apps)
- Social logins (Google Sign-In, etc.)

**Result if compromised:**

- Repo cloned and deleted  
- Identity hijacked for vendors / banks  
- Password resets everywhere  
- Silent shadow-admin access

---

### 3.3 Legal / Financial

- MA Secretary of State business portal
- IRS and MA DOR credentials
- Banking logins (business + personal)
- Merchant accounts / card processors
- Registered agent and mailing address

**Result if compromised:**

- Fake filings in LLC’s name  
- False officers/directors added  
- Bank accounts drained or frozen  
- New debt opened in LLC name  
- Mail intercepted or rerouted
