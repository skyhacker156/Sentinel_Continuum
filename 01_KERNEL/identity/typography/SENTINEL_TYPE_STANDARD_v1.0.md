Sentinel City — Canonical Typographic Identity Standard
Status: Active · Kernel-Level · Immutable
Classification: Plane A Representation · Plane B Expression · Cross-Plane Identity

1. Purpose

This standard establishes a single institutional typographic identity that must appear uniformly across:

digital documents (Plane A)

Goldilocks Paper documents (Plane B)

typewritten notices

stamped impressions

ledger entries

routing slips

annex forms

treasury memos

certifications

continuity seals

Typography is Sentinel’s voice.
This standard ensures every output, in every form, speaks with the same institutional tone.

This standard is immutable except by explicit Founder override.

2. Core Principle: Type Unity

Sentinel’s type must remain the same across all dimensions.
All expressions—digital, mechanical, inked, or embossed—must derive from the same typographic lineage.

No drift.
No alternates.
No contextual substitutions.
Unity of type = unity of institution.

3. Primary Typeface (Digital Plane A)

Canonical Digital Typeface:
EB Garamond — Sentinel Cut

This is the official typeface of:

charters

scrolls

kernel documents

routing directives

stitching doctrine

guardian protocols

ledger standards

all official markdown exports

Required Characteristics

Classical serif

Wide spacing

Slow, deliberate verticals

Humanist curves

Historical presence

Quiet institutional authority

Digital Weights Allowed

Regular

Italic

SemiBold

Small Caps (headers only)

No bold caps.
No sans-serif.
No decorative alternates.

4. Mechanical Expression (Typewriter Plane)

All 1920s Annex typewriters must produce a mechanical variant of the same type lineage.

Not a random typewriter font.
Not Courier.
Not vintage noise.

Instead, each typewriter must be calibrated to:

Sentinel Mechanical Serif (SMS-1923)
—a typographic profile that mimics:

EB Garamond skeleton

typewriter ink texture

mechanical irregularity

platen pressure variance

Required Mechanical Traits

Slight baseline drift (≤ 1.2%)

Variable strike weight

Serif preservation in simplified form

Narrow tracking

Consistent letter height across machines

Identical alphabetic structure to EB Garamond

Typewriter IDs & Imprint Rules
Typewriter	Mechanical Profile	Note
T-1 (Treasury)	SMS-1923 Variant A	Cleanest impression; used for financial documents
T-2 (Records)	SMS-1923 Variant B	Darker strike; used for certifications
T-3 (Harbor)	SMS-1923 Variant C	Lightest strike; used for freight & intake logs

Each uses the same alphabet, the same grammar, the same core skeleton.

Only texture varies.

5. Stamp Expression (Rubber & Steel Stamps)

Stamps must use:

Sentinel Imprint Serif (SIS-Embossed)
—a solid, block-aligned version of the same typographic lineage.

Stamp Requirements

All caps only

Narrow letterspace

Serif block forms preserved

No compression or stretching

Vertical alignment locked to baseline grid

Embossed height consistent (if physical)

Standard Stamp Examples
MERCANTILE ANNEX – RECEIVED
POSTED – MQ BOARD
CONTINUITY: VERIFIED
SEAL ALIGNED – CDV


Every stamp must “sound” like Sentinel type.

6. Ledger Script (Continuity Division)

For ledger entries, numbering, and penny acknowledgements:

Sentinel Ledger Script (SLS-Fine)
—a handwritten-style variant derived from Garamond strokes.

Usage

ledger line entries

carbon copy labels

penny acknowledgments

continuity envelope logs

triplicate numbering

Required Traits

narrow, elegant curves

consistent x-height

controlled slant (≤ 8°)

serif mimicry in handwritten form

archival ink simulation

The Ledger Script is the only handwritten-style allowed.

7. Page Geometry (Universal)

Every Sentinel document—digital or physical—must observe:

Margins

Top: 1.25 in

Bottom: 1.0 in

Left: 1.25 in

Right: 1.25 in

Line Spacing

1.22–1.28 (charter standard)

1.15 (annex memos)

1.30 (ledger entries)

Header Discipline

All caps

Small caps allowed

No bold heavy usage

Always left-aligned

Must include routing tag when applicable

8. Information Hierarchy

To preserve institutional voice:

Level 1 Headings

Small caps · Garamond · wide spacing

## SECTION HEADER

Level 2 Headings

### Subsection

Tables

Left-aligned; no borders except header underlines

Footers

Small caps or ledger script if archival

9. Cross-Plane Binding Rule

A document is invalid if its typography deviates from the Sentinel Type Standard.

It cannot be:

posted

stamped

sealed

archived

converged

notarized

or transmitted to Plane B

Without full type alignment.

This prevents identity drift over time.
