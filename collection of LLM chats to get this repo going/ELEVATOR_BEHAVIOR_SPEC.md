One path.

2. CORE BEHAVIOR
2.1. Summoning

The Elevator appears when:

Founder summons Stuart

Stuart invites a visitor downward

A ceremony scroll triggers movement

A Continuity Token verification passes

The Elevator never appears spontaneously.

2.2. Visual Identity

Across all engines the Elevator features:

Sentinel blue interior lighting

Parthenon-white marble threshold

Continuum Seal crest on the back wall

A soft, non-mechanical hum

A glowing floor sigil showing destination state

No matter what world the user is in, it is unmistakably the same Elevator.

2.3. Movement

The Elevator never teleports.

It always:

Closes doors

Descends (or ascends)

Opens doors into the new layer

Animation length may vary but perception of continuity must stay constant.
