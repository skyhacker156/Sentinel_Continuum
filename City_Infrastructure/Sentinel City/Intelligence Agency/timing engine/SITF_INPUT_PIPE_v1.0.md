### 4. Ingestion Sequence (19 steps – never reordered, never skipped)

1. Mail lands on marble → instant timestamp via wall clock synced to NIST  
2. Photograph envelope front (macro + ultrawide)  
3. Photograph envelope back  
4. Weigh entire piece (record to 0.01 g)  
5. Measure thickness with digital caliper  
6. Open with brass letter knife along top edge only (preserve all perforations)  
7. Photograph every inserted sheet – both sides – 600 dpi  
8. Photograph any inserts separately (checks, plastic cards, return envelopes)  
9. Log 19 forensic fields into `SITF_MAIL_ARTIFACT_LOG_v1.0.csv`  
10. Place original documents in acid-free glassine sleeve  
11. Carbon-copy every page (black → Daily Binder, blue → Municipal Records, red → Treasury if financial)  
12. Stamp carbon copies: COPY – MQ (Zone E) + CARBON COMPLETE  
13. Slide blue/red carbons through Routing Hatch  
14. Place glassine sleeve into Daily Binder behind carbon set  
15. Update physical wall chart (yarn + pins) with new ripple
