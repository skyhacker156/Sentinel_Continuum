# **2. Core Principles of Visibility**

All external discovery follows one of four principles:

### **2.1 Passive Propagation (Default)**

The world discovers you only when *you* have triggered a system that propagates outward
(e.g., LLC formation → state registry → data brokers → banks).

This is the safest mode and the current state of Sentinel Labs.

### **2.2 Algorithmic Harvesting**

Commercial entities scrape public registries and data feeds at variable intervals:

* daily (aggressive EIN scrapers)
* weekly (regional banks)
* monthly (national banks)
* quarterly (credit bureaus)

SITF monitors these latencies to reconstruct their internal pipelines.

### **2.3 Tripwire Activation**

Certain Founder actions act as **visibility detonators**:

* Filing EIN
* Opening bank account
* Creating website/domain
* Registering trademark
* Applying for business credit
* Pulling Dun & Bradstreet file
* Hitting IRS or SBA systems
* Engaging payroll/contractors
* Conducting financial transactions

Each detonator wakes up an entire category of watchers.

### **2.4 Cross-Plane Interference**

A real-world document, filing, or event that enters Sentinel City becomes:

* an artifact
* an intelligence signal
* a visibility ripple
* a timeline anchor

The SITF uses these artifacts to forecast the next ripples.

# **3. The SITF Visibility Quadrant Model**

SITF classifies every external entity into one of four quadrants:

```
               High Power
     Q1 ┌──────────────────────┐ Q2
        │ Federal Agencies     │
        │ (IRS, USPTO, SBA,    │
        │ FinCEN, Treasury)    │
        │ Latency: Fast/Slow   │
        │ Risk: High           │
Low     └──────────────────────┘──────────► Engagement
Power   Q3 ┌──────────────────────┐ Q4
        │ Commercial Scrapers     │
        │ (EIN spam, brokers,     │
        │ data harvesters)        │
        │ Latency: Very Fast      │
        │ Risk: Low               │
        └─────────────────────────┘ High
        Low                     High
        Visibility Latency
```

* **Q1: High Power / Low Frequency**
  → The most dangerous. IRS, Treasury, FinCEN, SBA.

* **Q2: High Power / High Frequency**
  → Patent Office, State level filings.

* **Q3: Low Power / High Frequency**
  → Noise layer: scrapers, spam, low-level marketing.

* **Q4: Medium Power / Medium Frequency**
  → Banks, credit bureaus, KYC networks.

Each ripple is categorized into its quadrant.
